# Basic API Automation

## Purpose
Demonstrates how Python communicates with external APIs.

## Workflow
```text
Python
  ↓
API request
  ↓
Receive JSON
  ↓
Process data
  ↓
Display or take action
```

## What It Teaches
- HTTP requests.
- API endpoints.
- JSON responses.
- Dictionaries and lists.
- Error handling.
- HTTP status codes.

## Enterprise Use
The same pattern is used with:
- Cloud APIs.
- Monitoring APIs.
- Ticketing APIs.
- Microsoft Graph.
- AWS APIs.
- Azure APIs.
- ServiceNow APIs.

## Important
API automation is the foundation for cloud automation.

## Run
```bash
python basic_api_automation.py
```
