# Security Automation

## Purpose
Automates basic security monitoring and administrative checks.

## Capabilities
- Failed-login detection.
- Security-log analysis.
- File-integrity checks.
- Certificate checks.
- User-access auditing.
- Security-event reporting.

## Supported Platforms
- Windows
- Ubuntu/Linux

## Enterprise Use
This automation supports SOC, Blue Team, infrastructure security, and system administration workflows.

## Important
This is defensive automation. It should be integrated with proper logging, SIEM, and incident-response processes in enterprise environments.

## Run
```bash
python security_automation.py
```
