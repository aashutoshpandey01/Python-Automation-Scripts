# Network Automation

## Purpose
Automates common network checks and information collection.

## What It Does
- Checks connectivity.
- Pings hosts.
- Checks TCP ports.
- Performs DNS checks.
- Collects local network information.
- Can be extended to network-device APIs or SSH automation.

## Enterprise Use
Useful for:
- Infrastructure troubleshooting.
- Connectivity validation.
- Service availability checks.
- Network operations.

## Supported Platforms
- Windows
- Ubuntu/Linux

## Run
```bash
python network_automation.py
```
