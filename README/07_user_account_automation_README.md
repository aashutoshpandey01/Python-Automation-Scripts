# User and Account Automation

## Purpose
Automates common local user and account operations.

## Operations
- Create users.
- Remove users.
- Disable accounts.
- Add users to groups.
- Create service accounts.

## Supported Platforms
- Windows
- Ubuntu/Linux

## Enterprise Use
The same automation concept is used in:
- Windows Server
- Active Directory workflows
- Linux administration
- Cloud IAM systems

## Important
User-management operations require elevated Administrator/root permissions.

## Run
```bash
python user_account_automation.py
```

## Security
Never hardcode user passwords or credentials in source code.
